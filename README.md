# home-school

Portal simples de estudos do 7º ano.

## Estrutura

- `/index.html` — página inicial com acesso às matérias
- `/ingles/index.html` — aula interativa de Inglês

Novas matérias devem ser adicionadas em pastas próprias na raiz (por exemplo, `/matematica/`, `/ciencias/`) e vinculadas no `index.html` principal.
